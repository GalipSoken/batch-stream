# 9. Sözlük

[← İçindekiler](../README.md)

| Terim | Kısa tanım |
| --- | --- |
| Broker | Kafka kümesindeki her bir sunucu |
| Consumer group | Bir topic'i birlikte, paylaşarak okuyan tüketiciler |
| Consumer lag | Tüketicinin kuyruğun ne kadar gerisinde kaldığı; stream sağlığının ana göstergesi |
| DAG | Airflow'da görevlerin sırasını tanımlayan yönlü grafik |
| DWH | Analitik sorgu için düzenlenmiş merkezi veri ambarı |
| ETL / ELT | Çek-dönüştür-yükle / çek-yükle-dönüştür |
| Lakehouse | Nesne deposu üzerinde tablo formatıyla (Iceberg, Delta) DWH özellikleri |
| OHLCV | Açılış, en yüksek, en düşük, kapanış, hacim |
| Parquet | Kolon bazlı, sıkıştırılmış dosya formatı |
| Sink / Source | Akışın yazıldığı hedef / okunduğu kaynak |
| Tick | Tek bir alım-satım işlemi kaydı |
| Topic | Kafka'da mesajların yazıldığı adlandırılmış akış |
| TSDB | Zaman serisi verisine optimize veritabanı |
| VWAP | Hacim ağırlıklı ortalama fiyat |
